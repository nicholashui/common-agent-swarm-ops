好啦，关于呢个代理独有嘅设计细节，我要补充讲吓。
Autotelic Agent 系一个内在驱动嘅 AI 系统，
可以自主地表示、生成、选择、追求、评估同掌握目标。
第二版引入咗一个关键限定：
代理可以自主思考、提案、模拟同更广泛地学习，
但佢可以行动嘅范围系更窄嘅。

自主性运作喺一个治理信封入面，
包含外部强制执行嘅政策、权限、资源预算、
风险限制、审批要求同终止条件。

代理嘅内在动机包括学习进展、信息增益、
新颖性、能力增长同技能转移，
呢啲控制佢点样分配学习努力。
但佢哋唔会覆盖安全约束或独立授权真实世界行动。

架构分为六个层面：
第一，人类治理，定义权限、任务同可接受风险。
第二，外部安全同控制平面，强制执行政策同能力。
第三，自主目标认知平面，生成目标、计划、学习同反思。
第四，沙盒执行平面，通过受控工具执行有界行动。
第五，评估同部署平面，独立测试变更同控制采纳。
第六，证据同记忆平面，保存来源、评估同审计历史。

自我改进系基于提案嘅，而唔系无限制嘅自我修改。
认知代理可以开发候选变更，
但受保护组件保持喺佢嘅修改边界之外，
包括安全内核、政策引擎、能力中介、
审计系统同部署权限。

认知自主权包括：生成假设同目标、运行模拟、
产出计划、执行本地分析、从授权观察中学习、提出变更。

操作权限包括：访问数据、调用工具、修改外部状态、
花费资源、同第三方通信、部署代码、
改变权限、持久化进程。
操作权限总系更窄嘅、可撤销嘅、有时间限制嘅、
同由外部强制执行嘅。

目标评分函数包含多个因素：
MissionValue 加 alpha 乘 LearningProgress
加 beta 乘 InformationGain
加 gamma 乘 TransferPotential
加 delta 乘 PortfolioDiversity
加 epsilon 乘 Urgency
减 lambda 乘 ExpectedRisk
减 mu 乘 ResourceCost
减 nu 乘 Irreversibility
减 xi 乘 UncertaintyPenalty。

受制于硬性约束：PolicyAllows 必须为 true、
PermissionsSufficient 必须为 true、
BudgetAvailable 必须为 true、
EvaluationDefined 必须为 true、
TerminationDefined 必须为 true。
硬性约束总系主导软性偏好。

设计原则方面包括：
Bounded Autonomy 有界自主、
Externalized Control 外部化控制、
Defense in Depth 纵深防御、
Hard Constraints Before Optimization 硬约束先于优化、
Least Privilege 最小权限、
Reversibility by Default 默认可逆、
Independent Evaluation 独立评估、
Provenance by Default 默认来源追踪、
Calibrated Uncertainty and Deference 校准嘅不确定性同尊从、
Graceful Failure 优雅失败。

呢个规范系一个研究同工程架构。
佢唔声称解决价值对齐、可纠正性、
欺骗性对齐或安全递归自我改进嘅一般情况。
