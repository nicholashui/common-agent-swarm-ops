我再详细补充吓 Controller Agent 嘅视频生成流程。
呢个代理嘅核心哲学好清晰：
用 Blender 构建完整嘅草稿作为精确导演，
然后用 AI 做高端渲染产出最终效果。
Blender 负责镜头角度、时间节奏、布局同姿态。
AI 负责细节、光照、材质嘅生成。
呢个混合方法系 2026 年最有效嘅可控视频生成方式。
从 Mickmumpitz 嘅教程提取嘅流程好详细。
第一步系喺 Blender 入面生成资产。
用 NVIDIA Video Generation Guide 嘅 Blender 插件，
配合 Llama 3.1 做对象头脑风暴。
TRELLIS 系 Microsoft 嘅工具喺 ComfyUI 入面使用，
可以从文本或预览生成带几何同纹理嘅 3D 资产。
优化网格要用 Decimate 加 Merge by Distance。
角色方面用 TRELLIS 生成然后 Rigify 自动绑定，
手动修正权重绑定。建议头同身体分开。
可选加入眼球做眼睛控制测试。
第二步系控制通道嘅导出，呢个非常关键。
深度通道：View Layer 启用 Depth，
Compositor 入面做 Invert 加可选 Normalize 同 RGB Curve，
增强前景然后导出图像序列或视频。
轮廓通道：切换到 Workbench 引擎启用 Outline 加 Cavity，
渲染黑白视频。替代方案有 Freestyle 或 ComfyUI 中嘅 Canny。
口型遮罩用于唇部同步：
喺口部区域动画化黑色遮罩，
黑色等于 AI 可以自由生成嘅区域用于唇部运动。
可以喺 After Effects 或 Blender Cryptomatte 做。
第三步系风格锁定同参考帧用 Flux。
用 Flux.2 klein 或 Flux 9B 工作流。
输入包括来自 Blender 嘅 clay/depth/outline，
加上最多四张参考图片可以合成到一张。
从任何着色提取 Canny。
迭代三个以上种子。输出用作引导或中间帧。
第四步系视频生成用 LTX-2.3。
ComfyUI 工作流用 JSON 拖放。
模型有 LTX-2.3 FP8、NVFP4 针对 50 系列优化、GGUF 低显存版。
输入包括参考图片序列、深度加轮廓合并、可选口型遮罩、对话音频。
关键设置有驱动视频强度越低越自由、
引导帧开始中间结束加强度例如 0.75、唇部同步激活。
分辨率要整除 64。提示描述时间事件同表情。
速度范例约两分钟 330 帧喺 RTX 5090 上。
第五步系升级同完成。
用 NVIDIA RTX Video Super Resolution 节点免费升到 4K。
最终装配喺 DaVinci Resolve 做音频、SFX、轻度调色、模拟效果。
关键提示：骨骼唔需要完美因为只系 AI 嘅引导。
深度加轮廓合并可以得到最强嘅结构。
口型遮罩解决控制通道上嘅静态唇部问题。
预合并开始同结束帧可以减少镜头扭曲伪影。
多角色控制方面：
训练角色 LoRA 用多角度多表情数据集。
用区域钩子或遮罩确保每个 LoRA 只影响对应区域。
用 SAM2 自动分割或手动做区域遮罩。
Hunyuan 3D 生成 3D 角色然后清理再 Rigify 确保一致性。
导出深度同 tile ControlNet 参考。
用关键帧插值 ControlNet 强度前高后低，
锁定构图同时允许细节生成。
环境方面用 360 度 Flux 加倒深度图作为发射纹理。
完整工作流五个阶段清晰分工，
从预制作到最终打磨每步都有明确嘅输入输出。

最后总结：Controller Agent 嘅核心价值在于将精确控制同 AI 创意结合。
Blender 提供像素级嘅精确控制。
AI 提供照片级嘅真实感同细节。
两者结合产出嘅结果远超任何单一方法。
