# API Portal — step-by-step user guide

**Screen:** API Portal  
**Route:** `/developer/api`  
**Who it’s for:** Developers exploring portal projections and try-it when authorized.

---

## 1. Open API Portal

1. Sign in → **DEVELOPER & HELP** → API portal, or `/developer/api`.
2. Confirm nav sections, endpoint explorer, tokens, webhooks as projected.

---

## 2. Navigate portal sections

1. Click left nav items to switch portal sections.
2. Use search when present to filter endpoints/docs locally.

---

## 3. Explore endpoints

1. Select an endpoint card.
2. Review method, path, and sample tabs.
3. **Try it** only runs when host-authorized; otherwise fail-closed.

---

## 4. Tokens and webhooks

1. Token/webhook lists are projections.
2. Create/rotate controls require authorized portal actions.
3. Never paste production secrets into demo fields.

---

## 5. Help

1. Help panel resolves `/developer/api` → `/docs/developer/api/userguide.md`.
2. OpenAPI remains server truth; UI does not invent contracts.
