# Activity — step-by-step user guide

**Screen:** Activity & Ops Intelligence  
**Route:** `/activity`  
**Who it’s for:** Operators reviewing execution boards, tables, and timelines.

---

## 1. Open Activity

1. Sign in → **OPERATE** → **Activity**, or `/activity`.
2. Confirm header, search, date range, and view modes (Board / Table / Timeline).

---

## 2. Search and date range

1. Type in search to filter cards/rows locally.
2. Click the date-range chip to cycle ranges (local presentation).
3. Status line announces the selected range when changed.

---

## 3. View modes

1. **Board** — columns of execution cards.
2. **Table** — tabular run/agent rows.
3. **Timeline** — lanes/bars overview.
4. Active mode is pressed/highlighted.

---

## 4. Filter chips and toggles

1. Click filter chips to apply local facets (active state).
2. Use toggles such as outdated-only / contributed-only when present.
3. Combine with search; empty results show an empty state.

---

## 5. Card and row actions

1. Select cards/rows as needed for multi-select if available.
2. **Inspect** / open links navigate or request host inspect intents.
3. Governed actions fail closed without action references.

---

## 6. Live update

1. Toggle **Live Update** when shown.
2. Live stream depends on authorized SSE; otherwise status explains pending authorization.

---

## 7. Help

1. **Help** drawer → this guide for `/activity`.
2. **Documents** → full-page guide.

---

## 8. Safety notes

- Statuses are projected; do not invent run authority.
- Filters are presentation-only until a host query contract exists.
