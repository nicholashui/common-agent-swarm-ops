# Profile — step-by-step user guide

**Screen:** Profile  
**Route:** `/profile`  
**Who it’s for:** Operators viewing their identity/workspace profile projection.

---

## 1. Open Profile

1. Sign in → footer **Profile** or **ACCOUNT** → Profile, or `/profile`.
2. Confirm profile sections and fields from projection.

---

## 2. Review identity

1. Read email/workspace labels returned by session/projection.
2. Switch profile sections if tabs/nav exist.

---

## 3. Edit (when allowed)

1. Change editable fields only when the projection exposes edit intents.
2. Save through onAction; fail-closed without host profile mutation contract.
3. Do not invent elevated roles in the browser.

---

## 4. Help

1. Help panel → `/docs/profile/userguide.md`.
