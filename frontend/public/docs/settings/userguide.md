# Settings — step-by-step user guide

**Screen:** Settings  
**Route:** `/settings`  
**Who it’s for:** Operators adjusting workspace preferences (local or host-authorized).

---

## 1. Open Settings

1. Sign in → **ACCOUNT** → **Settings**, or `/settings`.
2. Confirm section navigation and preference fields.

---

## 2. Switch sections

1. Click a settings section in the side nav.
2. Active section content loads in the main pane.

---

## 3. Edit preferences

1. Change fields as labeled.
2. Save when a save control exists (session or host-authorized prefs).
3. Never enter production API keys or secrets into generic preference fields.

---

## 4. What settings cannot do

1. Settings alone cannot enable production media activation.
2. Host-only flags remain server-controlled.

---

## 5. Help

1. Help → this guide for `/settings`.
