# Knowledge — step-by-step user guide

**Screen:** Knowledge  
**Route:** `/knowledge`  
**Who it’s for:** Operators searching knowledge projections and (when contracted) ingestion.

---

## 1. Open Knowledge

1. Sign in → **KNOWLEDGE & QUALITY** → **Knowledge**, or `/knowledge`.
2. Confirm search, result list, and detail tabs when projected.

---

## 2. Search

1. Enter a query in the knowledge search field.
2. Submit/search triggers `knowledge.search` through the action bridge when wired.
3. Results are redacted projections; no raw protected corpus dump.

---

## 3. Browse results

1. Click a result to open detail tabs.
2. Switch detail tabs as labeled.
3. Use evidence/reference links only as opaque host refs.

---

## 4. Ingestion (when available)

1. If an ingestion form appears, enter content or import **reference** (not browser-fetched secrets).
2. Client validation is **non-authoritative**.
3. Without a generated authorized ingestion contract, submit stays unavailable/fail-closed.
4. Never paste credentials into knowledge content.

---

## 5. Help

1. **Help** drawer documents this route.
2. Full ingestion security is server-side; UI only collects untrusted data safely.
