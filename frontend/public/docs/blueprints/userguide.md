# Blueprints — step-by-step user guide

**Screen:** Blueprints gallery  
**Route:** `/blueprints`  
**Who it’s for:** Operators browsing reusable blueprint cards and instantiate intents.

---

## 1. Open Blueprints

1. Sign in → menu **BUILD** → **Blueprints** (or `/blueprints`).
2. Confirm gallery of blueprint cards and search/filter controls.

---

## 2. Search the gallery

1. Type in the search box to filter blueprint titles/descriptions (local filter).
2. Clear the box to show the full gallery again.

---

## 3. Inspect a blueprint card

1. Click a card (or open preview if separate).
2. Read title, summary, pins, and safety notes.
3. Note that pack_spine / catalog previews are **not** automatic production realization.

---

## 4. Instantiate

1. Click **Instantiate** (or primary CTA) on a blueprint.
2. If no host action reference exists, the UI fails closed with an authorized-action message.
3. On success, follow status feedback and any linked canvas/composer destination.

---

## 5. Secondary actions

1. Use any secondary buttons (compare, open detail) as labeled.
2. Governed actions always require host eligibility.

---

## 6. Help

1. **Help** → User guide tab (this document for `/blueprints`).
2. **Documents** → full-page view of the same guide.

---

## 7. Safety notes

- Instantiation never activates production agents/providers from the browser alone.
- Treat gallery content as projection/catalog data.
