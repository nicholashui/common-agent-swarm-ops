# Mobile ops — step-by-step user guide

**Screen:** Mobile compact ops  
**Route:** `/mobile`  
**Who it’s for:** Operators using the compact mobile-oriented projection.

---

## 1. Open Mobile

1. Sign in and open `/mobile` (or the mobile entry if linked).
2. Confirm compact device-style layout and tabs.

---

## 2. Switch tabs

1. Tap/click bottom or top tabs to switch compact views.
2. Same eligibility rules as desktop Homes apply.

---

## 3. Actions

1. Primary compact actions use the same onAction bridge.
2. Fail-closed messages appear when host authority is missing.
3. Mobile layout never relaxes security rules.

---

## 4. Help

1. Help drawer works the same as desktop when shell chrome is present.
2. Prefer landscape/desktop for dense registry work when needed.
