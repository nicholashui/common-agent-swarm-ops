# Costs — step-by-step user guide

**Screen:** Cost & token analytics  
**Route:** `/costs`  
**Who it’s for:** Operators reviewing projected spend and recommendations.

---

## 1. Open Costs

1. Sign in → **OPERATE** → **Costs**, or `/costs`.
2. Confirm metrics, swarm breakdown, agent usage, and period control.

---

## 2. Search and period

1. Search filters swarm/agent rows locally.
2. Click the **period** chip to cycle ranges (local presentation).
3. Status announces the selected period.

---

## 3. Explore breakdowns

1. Click a swarm bar/row to select it.
2. Review agent usage table for the selection or full list.
3. Numbers are **projections**, not billing authority.

---

## 4. Budgets and recommendations

1. **Set/edit budget** requires authorized finance action (fail-closed).
2. **Apply recommendation** requires proposal + approval stages (fail-closed).
3. **Export report** requires authorized export job.

---

## 5. Help

1. Help panel → `/docs/costs/userguide.md`.
2. Do not treat UI totals as invoice truth without host finance systems.
