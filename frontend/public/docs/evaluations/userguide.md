# Evaluations — step-by-step user guide

**Screen:** Eval / Improvement  
**Route:** `/evaluations`  
**Who it’s for:** Operators reviewing campaigns and requesting eval runs.

---

## 1. Open Evaluations

1. Sign in → **KNOWLEDGE & QUALITY** → eval item, or `/evaluations`.
2. Confirm campaign list, results, and primary actions.

---

## 2. Browse campaigns

1. Scan campaign cards/rows and status.
2. Open review when available (redacted diff + impact only).

---

## 3. Run a campaign

1. Click **Run campaign** (or primary run control).
2. Runtime calls host evaluation when available.
3. If unavailable, fail-closed feedback appears.

---

## 4. Governance-related buttons

1. **Approve & merge**, **Promote winner**, **Reject** require proposal/approval/canary stages.
2. Clicking them without action refs produces honest fail-closed messages.
3. Eval pass alone never publishes.

---

## 5. Help

1. Help panel → this guide for `/evaluations`.
2. Keep eval evidence redacted; no secrets in UI.
