# Onboarding — step-by-step user guide

**Screen:** Onboarding  
**Route:** `/onboarding`  
**Who it’s for:** New operators walking guided setup steps.

---

## 1. Open Onboarding

1. Sign in → **DEVELOPER & HELP** → Onboarding, or `/onboarding`.
2. Confirm step list and continue controls.

---

## 2. Walk steps

1. Read the current step content.
2. Click **Continue** / next to advance local step state.
3. Use back/previous when available.
4. Optional skip only if the projection allows it.

---

## 3. Selections

1. Select agents/options when the step asks.
2. Clear selection with clear controls if provided.
3. Progress is session presentation unless host persists onboarding.

---

## 4. Finish

1. Complete the final step.
2. Follow any link to Dashboard/Registry.
3. Onboarding alone never claims production readiness.

---

## 5. Help

1. Help drawer documents `/onboarding`.
2. Host gates (auth, packs) still apply after onboarding.
